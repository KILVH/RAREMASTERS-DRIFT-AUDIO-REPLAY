# RAREMASTERS DRIFT — AUDIO & REPLAY

Отдельная версия существующей игры, 3 октября 2026. Старые BETA и MOBILE не изменяются.

- Двигатель и шины: один AudioContext, три постоянных петли, однократное декодирование, параметры 10 раз/с. SFX: четыре слота и ограничение частоты. Музыка остаётся в существующем плеере; добавлен MASTER.
- Мобильные кнопки: тормоз слева, газ справа, ручник над газом; поддержаны несколько пальцев и скольжение газ ↔ ручник.
- На «Магазин Михалыч» и «ЭКО Форум» визуальный масштаб автомобилей увеличен на 16%, физические размеры сохранены.
- Хорошие завершённые заезды записываются автоматически с частотой 15 Гц. До шести записей на трассу и направление сохраняются в IndexedDB. NPC повторяют их по очереди; между финишем и стартом едут обычным AI. При отсутствии записей работает прежний AI. Небезопасные записи отбрасываются, препятствие во время replay останавливает воспроизведение и возвращает AI.
- В настройках есть выключенный по умолчанию режим разработчика. После ввода выданного владельцу кода доступны контент, деньги, машины, персонажи, соперники, трассы, управление replay и DEBUG. TEST означает траекторию AI, а не запись игрока.
- Выбор трасс — крупные горизонтальные карточки с прокруткой.

## Запуск и проверка

Статическая игра, сборка npm не нужна. Запустите `python -m http.server 8000` из этой папки и откройте `http://localhost:8000/`. Для GitHub Pages: ветка main, папка root, файл .nojekyll уже включён.

`npm test` запускает автономные проверки Node без сторонних пакетов. Результаты сохраняются в verification. Подробности и ограничения: [AUDIO_REPLAY_REPORT.md](AUDIO_REPLAY_REPORT.md). Остальные отчёты относятся к предыдущим версиям.

Новая версия использует отдельные ключи прогресса и базу replay. Прежний прогресс на том же домене копируется при первом запуске, прежние результаты доступны только для чтения. Обновление старой базы не выполняется. Экспорт доступен в настройках. Прогресс и записи хранятся локально в браузере устройства.

## Проверка на телефоне

Откройте опубликованную ссылку в альбомной ориентации. Сравните одну трассу со всеми звуками, только двигателем, двигателем + эффектами и с выключенным MASTER. В режиме разработчика DEBUG показывает FPS, время физики/отрисовки и число аудиоисточников. Проверка на компьютере не заменяет измерения на вашем телефоне.
